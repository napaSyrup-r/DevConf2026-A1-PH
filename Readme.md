# DevConf2026

A modern and responsive conference landing page built using **HTML5** and **CSS3**. This project represents the official website for **DevConf 2026**, showcasing conference information, speakers, ticket plans, sponsors, and more.

## Features

- Responsive navigation bar
- Hero banner with background image
- Meet the Speakers section
- Ticket Pricing section
- Sponsors section
- Footer with social media links
- Modern UI using CSS Grid and Flexbox

## Technologies Used

- HTML5
- CSS3
- Font Awesome (for social media icons)
- Google Fonts (Inter)
